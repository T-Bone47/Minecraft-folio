## 1. The 60-Second Recruiter Evaluation Mandate

Technical recruiters spend an average of 30 to 60 seconds reviewing a candidate's portfolio. In traditional 3D/gaming portfolios, recruiters are often blocked by:
- Complex WASD controls and pointer lock barriers.
- Long loading spinners without immediate value.
- Confusing gamified metaphors that obscure actual technical skills.

Frontier Director 2.0 solves this with a **Zero-Hurdle, Sub-60-Second Value Path**:

```
+-----------------------------------------------------------------------------------+
|                        RECRUITER 60-SECOND EVALUATION PATH                        |
+-----------------------------------------------------------------------------------+
|                                                                                   |
|  [0 - 5 Seconds]     Candidate Credentials & Core Engineering Disciplines         |
|                      - Asish Oliver M: Motorsport Software & Applied AI/ML        |
|                                                                                   |
|  [5 - 20 Seconds]    Instant Visual Demonstration via Frontier Director           |
|                      - 60s guided showcase (zero driving required)                |

+-----------------------------------------------------------------------------------+
```

## 3. Shareable Artifacts for Hiring Teams

Frontier Director provides one-click tools for recruiters to share candidates with engineering teams:
- **Copy Deep Link:** Directly captures the active demonstration and evidence layer (e.g. `/experience/motorsport/evidence?layer=algorithm`).
- **Social Preview Cards:** Optimized OpenGraph metadata displays professional cards in Slack, LinkedIn, and Teams.
- **2D Complete Parity:** Shareable links work seamlessly on mobile phones and enterprise networks with WebGL disabled.
- **Direct Candidate Contact:** One-click email to `dreamteamoliver@gmail.com` and GitHub profile `https://github.com/T-Bone47`.

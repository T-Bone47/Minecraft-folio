## 2. Mission Progression & Non-Gating Invariants

### 2.1 Free Navigation Guarantees
- The mission is strictly an **optional guided narrative**.
- Completing the mission is **never required** to view Asish's resume, contact info, GitHub links, or project pages.
- Visitors can freely walk away, skip ahead, reset progress, or resume at any time.

### 2.2 Objective Milestones
1. `DRIVE_OR_LOAD`: Completing a lap in the Frontier-01 or clicking "Load Bundled Benchmark" advances the mission to `INGEST_PIPELINE`.
2. `INGEST_PIPELINE`: Visiting the Telemetry Tower and opening the Pipeline Observatory advances the mission to `ANALYSE_FEATURES`.
3. `ANALYSE_FEATURES`: Visiting the AI/ML Lab and inspecting the engineered features advances to `ENGINEERING_DECISION`.
4. `ENGINEERING_DECISION`: Selecting and applying any what-if scenario advances the mission to `CASE_STUDY_UNLOCKED`.
5. `CASE_STUDY_UNLOCKED`: Awards the "Frontier Twin Architect" achievement and displays the complete architecture case study.
